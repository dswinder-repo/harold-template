# Cloud morning brief drafts

Optional. If you enable `.github/workflows/morning-brief.yml`, a GitHub Actions job writes a draft of Steps 1 and 2 of `playbook/core/morning-brief.md` here as `YYYY-MM-DD.md` before you wake up, and commits it.

These files are saved drafts. Nothing reads them automatically and nothing sends them to you: open the day's file yourself, or ask Harold to read it when you say good morning. If you want it delivered (email, chat), that is a step you add.
