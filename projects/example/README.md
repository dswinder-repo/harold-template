# Example Project

Starter example of a project folder. `harold/projects.md` points here (`- folder: projects/example`), so `bin/harold where example` resolves to this folder, the search index covers it, and `bin/harold close` treats changes here as knowledge that needs a daily note.

Put a project's working files here: notes, drafts, research, the canonical version of each document. Keep the file map in this README.

| Path | What |
|------|------|
| `notes/` | Working notes |
| `drafts/` | Documents in progress |

Replace this folder with your first real project, or delete it and remove its entry from `harold/projects.md`.
